# One-Liner Laugh Lab

One short funny line — the excuse a robot vacuum gives after eating a sock — written for the [Make.fun bounty](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae).

`main.py` writes the line to `/output/entry.txt`:

> I ate one sock. You own fourteen. This is a rounding error, not a crime.

Run it with `python3 main.py`.
